Ở pha cuối, MySQL `data_length` cộng hai bảng là 5.029.888 byte trong lượt này so với
4.882.432 byte trong kết quả gốc. MongoDB `storageSize` lần lượt là 1.155.072 và
1.159.168 byte. Các số này là snapshot cấp phát của từng lượt. MySQL mô tả `data_length`
của InnoDB là ước lượng diện tích cấp phát cho clustered index. MongoDB ghi `storageSize`
cho phần document và đo index riêng. [Kết quả gốc](../../experiments/storage/results-initial.json) ·
[MySQL TABLES](https://dev.mysql.com/doc/refman/8.4/en/information-schema-tables-table.html) ·
[MongoDB collStats 8.0](https://www.mongodb.com/docs/v8.0/reference/command/collstats/)

## Tái tạo và bàn giao

Từ gốc repo có `.env.docker`, chạy các lệnh sau khi MySQL lab và MongoDB lab đều healthy.
Để chạy Playwright bằng cấu hình mặc định, cần cổng `3101` và `5174` trống cùng Chromium hoặc Edge.

```powershell
npm.cmd test --prefix backend
node --env-file=.env.docker backend/tests-db/catalog.cjs
npm.cmd run build --prefix frontend
npm.cmd test --prefix frontend -- catalog.spec.js
node experiments/storage/run.cjs
```

Các phép thử ghi vào schema hoặc collection tạm trên lab. Phần đối chiếu cột, `UNIQUE` và FK
trên schema app local đã có [kết quả chỉ đọc](../../database/mysql/README.md#migration-audit).
Chuyển bản ghi này cho Đạt để xử lý P3 và ghi nhận review thành viên. Cơ chế phiên chung hai vai trò
tiếp tục theo [bàn giao A](../handoffs/a-acceptance-2026-11-16.md).
